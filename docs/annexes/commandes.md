# Référence des commandes

| Outil | Usage |
|---|---|
| `auditctl` | règles audit actives |
| `augenrules` | charger les règles persistantes |
| `ausearch` | rechercher des événements |
| `aureport` | produire des rapports |
| `aa-status` | état AppArmor |
| `aa-enforce` / `aa-complain` | changer le mode d'un profil |
| `apparmor_parser` | valider/charger un profil |
| `sestatus` | état SELinux |
| `semanage` | objets persistants SELinux |
| `restorecon` | restaurer les contextes |
| `ausearch -m AVC` | rechercher des refus SELinux |
| `semodule` | gérer les modules |
