# Fichiers importants

| Domaine | Fichiers/répertoires |
|---|---|
| auditd | `/etc/audit/auditd.conf`, `/etc/audit/rules.d/`, `/var/log/audit/` |
| AppArmor | `/etc/apparmor.d/`, `/etc/apparmor.d/tunables/` |
| SELinux | `/etc/selinux/config`, `/etc/selinux/targeted/`, contextes XATTR |
| journald | `/etc/systemd/journald.conf`, journal système |

Les chemins de journaux et profils peuvent être modifiés par la distribution ou sa politique de packaging.
