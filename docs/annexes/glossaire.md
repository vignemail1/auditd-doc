# Glossaire

- **AVC** : décision de contrôle d'accès SELinux journalisée.
- **DAC** : contrôle d'accès discrétionnaire Unix.
- **MAC** : contrôle d'accès obligatoire.
- **auid** : identifiant d'audit associé à la session.
- **contexte** : étiquette SELinux portée par un sujet ou objet.
- **domaine** : type SELinux d'un processus.
- **profil** : politique AppArmor associée à un programme.
- **booléen** : option de politique SELinux activable dynamiquement.
- **enforcing** : mode où les refus sont appliqués.
- **complain/permissive** : mode de diagnostic qui journalise sans bloquer.
