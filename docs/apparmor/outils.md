# AppArmor — outils complémentaires

- `aa-status`, `aa-enabled` : état ;
- `apparmor_parser` : validation et chargement ;
- `aa-enforce`, `aa-complain`, `aa-disable` : modes ;
- `aa-genprof`, `aa-logprof` : construction assistée ;
- `aa-exec` : exécution avec un profil ;
- `apparmor-utils` : utilitaires ;
- `auditd`, `ausearch` et journald : corrélation ;
- outils de test applicatif et CI : validation des parcours.

Conserver les profils dans un dépôt et tester leur chargement sur chaque version de distribution supportée.
