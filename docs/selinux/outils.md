# SELinux — outils complémentaires

- `sestatus`, `getenforce`, `setenforce` : état et mode ;
- `semanage` : contextes, ports et booléens persistants ;
- `restorecon`, `matchpathcon` : étiquetage ;
- `sesearch`, `seinfo` : interrogation de politique ;
- `semodule` : modules ;
- `ausearch`, `audit2why`, `sealert` : analyse des AVC ;
- `audit2allow` : génération de proposition, jamais validation automatique ;
- OpenSCAP et SCAP Security Guide : conformité.

Les noms et paquets peuvent différer selon Fedora, RHEL, CentOS Stream, Debian ou Ubuntu.
